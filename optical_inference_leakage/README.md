# Computation

[recompute.py](recompute.py) rebuilds the measured comparison using NumPy and SciPy. [cutfloor.py](cutfloor.py) evaluates a conditional dual bound over the variance grid; [floors.py](floors.py) supplies the approximate-switching penalty. [attacks.py](attacks.py) simulates a homodyne client, while [leakage.py](leakage.py) supplies optical entropy and Gaussian-channel capacity. [fidelity.py](fidelity.py) checks product moments on a small truncated optical instance.

For new measurements, [fetch.py](fetch.py) downloads pinned inputs, [llm.py](llm.py) adds independent matrix noise to every product, and [gpu.py](gpu.py) tunes on validation before evaluating the test split. The same GPU calculation also retains the compressed activation spectra for future inspection. [calib.py](calib.py) defines the quality interval. [cases.py](cases.py) and [paths.py](paths.py) hold experiment constants and immutable input revisions.

[real_copy_data.py](real_copy_data.py) verifies the pinned weight file and exports one real crop with simulated cumulative copies, error statistics and provenance outside the repository. [figure_data.py](figure_data.py) exports the matrix atlas and floor comparisons. [hero_data.py](hero_data.py) exports expected copy errors and leakage at every integer text count from 1 to 489, combining tied observations before counting weights. These export data only. [presentation.py](presentation.py) writes the two result READMEs from the checked tables so their numerical prose cannot drift independently.

To port the calculation, supply matching matrix shapes, mean squares, variances, gradients and ranks. Preserve the distinction between separate noisy views and uniquely counted weights, and check the [class and assumptions](../THEORY.md) before interpreting a floor. [Commands](../REPRODUCE.md) cover both arithmetic reproduction and fresh measurements.
